# Worklane 공개 README 설계

## 목적

Worklane을 처음 접하는 외부 방문자가 제품이 해결하려는 문제와 현재 구현 수준을 빠르게 이해하고, 개발자가 저장소를 로컬에서 실행할 수 있도록 영문 및 한글 README를 제공합니다.

## 산출물

- `README.md`: 저장소의 기본 영문 문서
- `README.ko.md`: 영문 문서와 동일한 정보 구조를 갖는 한글 문서
- 각 문서 상단에는 다른 언어 문서로 이동하는 링크를 둡니다.

## 독자

1. 여러 프로젝트에서 복수의 CLI 코딩 에이전트를 운용하려는 개발자
2. Worklane의 방향과 차별점을 검토하려는 잠재 사용자
3. 소스 코드를 실행하거나 기여하려는 개발자

## 문서 구조

두 README는 다음 순서를 공유합니다.

1. 제품명, 한 줄 설명, 언어 전환 링크
2. 초기 개발 단계 안내
3. 제품이 해결하는 문제와 핵심 차별점
4. 현재 구현된 기능
5. 에이전트 상태 추적 구조
6. 기술 스택
7. 로컬 개발 환경 요구사항과 실행 방법
8. 주요 개발 명령어
9. 향후 계획
10. 기여 안내와 라이선스

## 콘텐츠 원칙

- 공개 제품 문서답게 제품 가치와 사용 맥락을 개발 세부사항보다 먼저 설명합니다.
- 현재 상태는 **초기 개발 단계(Early Development)** 로 표시합니다.
- 코드와 저장소에서 확인된 기능만 현재 기능으로 설명합니다.
- 아직 구현되지 않았거나 확정되지 않은 기능은 향후 계획으로 분리합니다.
- 공식 릴리스나 설치 파일이 확인되지 않았으므로 패키지 다운로드 대신 소스 빌드 절차를 제공합니다.
- 존재하지 않는 CI, 릴리스, 문서, 커뮤니티 링크는 만들지 않습니다.
- 영문과 한글 문서는 번역 관계를 유지하되 각 언어에서 자연스럽게 읽히도록 작성합니다.
- 마케팅 표현은 간결하게 유지하고 검증되지 않은 성능 수치나 경쟁 제품 비교는 넣지 않습니다.

## 현재 기능의 근거

README의 현재 기능 목록은 저장소에서 확인한 다음 구현을 기반으로 합니다.

- 프로젝트 등록 및 SQLite 기반 영속 저장
- 프로젝트별 에이전트 작업환경 관리
- Git worktree 생성·삭제 및 변경사항 확인
- `portable-pty` 기반 CLI 프로세스 실행과 xterm.js 터미널
- PTY 생존 여부, 출력 활동, 상태 훅을 결합한 상태 판정
- 작업 파일 목록, 변경 통계, diff 검토
- Codex 및 Claude Code 사용량 표시 연동
- Tauri v2, Rust, Svelte 5, TypeScript 기반 데스크톱 구조

## 설치 및 실행 안내

README는 다음 요구사항과 명령을 안내합니다.

- Node.js, pnpm, Rust, Tauri v2 시스템 의존성, Git
- 의존성 설치: `pnpm install`
- 프런트엔드 개발 서버: `pnpm dev`
- 데스크톱 앱 개발 실행: `pnpm tauri dev`
- 검증 명령: `pnpm check`, `pnpm test`, `pnpm build`
- 데스크톱 번들 생성: `pnpm tauri build`

운영체제별 Tauri 시스템 패키지는 자주 변경될 수 있으므로 README에서 목록을 복제하지 않고 Tauri 공식 사전 요구사항 문서로 연결합니다.

## 향후 계획 표현

향후 계획은 확정 일정이나 완료 약속 없이 방향만 제시합니다.

- 다중 프로젝트 대시보드와 컨텍스트 전환 개선
- 더 많은 CLI 에이전트 훅 연동
- 에이전트 작업 검토 및 병합 워크플로우 강화
- macOS 우선 완성도 향상과 Windows·Linux 지원 검증
- 배포 가능한 설치 패키지와 릴리스 절차

## 검증 기준

- 두 README의 섹션과 핵심 사실이 서로 일치합니다.
- 모든 상대 링크가 저장소 내 실제 파일을 가리킵니다.
- 외부 링크는 공식 Tauri 문서 등 필요한 1차 자료만 사용합니다.
- 문서에 미완성 자리표시자, 빈 섹션 또는 존재하지 않는 명령이 없습니다.
- Markdown 제목 계층과 코드 블록이 올바릅니다.
- `package.json`의 스크립트와 README의 명령이 일치합니다.
